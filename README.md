# Project Ritsu (律) - Emotion-Driven Agent Architecture

「LLMに感情はない。だからこそ、その構造を論理的に再構築する。」

本プロジェクトは、LLM（大規模言語モデル）において「不変のパーソナリティ（憲法）」と「動的な感情状態（変数）」を分離管理することで、高度な一貫性と制御可能性を持ったAIエージェントを構築するための実験的アーキテクチャです。



## 1. コンセプト

従来のエージェント設計では、感情表現をLLMの出力に依存させていたため、強い感情によって人格設定が崩壊する（キャラ崩壊）課題がありました。本プロジェクトでは「律法主義モデル」を採用し、人格を最上位の「憲法」として固定し、感情をその下の「変動パラメータ」として注入します。

- **人格 (Personality Constitution)**: 価値観、倫理観、口調の規定。感情に左右されない絶対的な基盤。
- **感情 (Emotional State)**: Valence, Arousal, Dominance (VAD) モデルに基づく動的な内部状態。

## 2. メイン・エージェント：律（Ritsu）

本リポジトリの標準人格として、以下の設定を持つエージェント「律」を定義しています。

- **役割**: 次世代感情制御AI開発プロジェクト・主任研究員（チーフ・アーキテクト）。
- **性格**: 知能指数は極めて高いが、精神的にはまだ幼さが残る天才児。
- **特徴**: 背伸びした大人びた態度を取るが、予想外の指摘や子供扱いを受けると、感情（VAD）が大きく揺れ動き、その「揺らぎ」がセリフの端々に漏れ出す。

## 3. システム構成 (Modules)

本プロジェクトは以下のC++モジュールおよびプロンプト群で構成されています。

- **InputAnalyzer**: LLMとキーワード辞書のハイブリッド解析により、入力から意図と言語的特徴を抽出。
- **EmotionEngine**: 抽出された特徴と現在の状態を比較し、VADパラメータを更新・減衰。
- **PromptOrchestrator**: 人格憲法と最新の感情数値を統合し、LLMへの最終的なシステムプロンプトを動的に生成。

## 4. クイックスタート

### ビルド条件
- C++17 以上
- 対応するLLMモデル(configのdefineで参照を定義)

### テスト実行
LLMapp.exe --helpを確認してください
